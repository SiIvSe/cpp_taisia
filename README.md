# cpp_taisia
A simple girlfriend AI project ib C++. Implemented via llama_cpp
# консольный чат с LLM

Проект представляет собой консольное приложение на C++, которое использует библиотеку [llama.cpp](https://github.com/ggerganov/llama.cpp) для запуска языковой модели в формате GGUF. Приложение поддерживает диалог с моделью, сохраняет историю переписки в JSONL-файл и корректно работает с русским языком в Windows.

## Возможности

- Загрузка модели GGUF (например, Dolphin-Mistral-24B).
- Генерация ответа с использованием greedy-семплинга.
- Поддержка системного промпта (на русском языке).
- Сохранение истории запросов и ответов в `history.jsonl`.
- Работа в интерактивном режиме: ввод вопросов, выход по команде `выход` или `.`.
- Поддержка CUDA (ускорение на GPU).

## Требования

- **Компилятор** с поддержкой C++17 (MSVC, GCC, Clang).
- **CMake** 3.15 или новее.
- **Git** (для клонирования подмодулей).
- **CUDA Toolkit** (опционально, для GPU).
- **Модель** в формате GGUF (скачать, например, с Hugging Face).

## Сборка проекта

### 1. Клонирование репозитория

```bash
git clone --recursive https://github.com/your-repo/LlamaTest.git
cd LlamaTest
```

Если вы клонировали без `--recursive`, выполните:

```bash
git submodule update --init --recursive
```

### 2. Настройка CMake

Проект предполагает наличие поддиректории `llama.cpp` с библиотекой. Убедитесь, что она присутствует.

Сборка с поддержкой CUDA (рекомендуется):

```bash
cmake -B build -DGGML_CUDA=ON
```

Сборка только на CPU:

```bash
cmake -B build
```

На Windows с Visual Studio и Ninja можно использовать предоставленный `CMakeSettings.json`.

### 3. Компиляция

```bash
cmake --build build --config Release
```

Исполняемый файл `MyLlamaApp` появится в `build/Release/` (или `build/`, в зависимости от генератора).

## Использование

### Подготовка модели

Скачайте GGUF-модель и укажите путь к ней в коде (переменная `model_path` в `main.cpp`).  
По умолчанию используется путь:

```
C:/Users/SiIvSe/.lmstudio/models/bartowski/cognitivecomputations_Dolphin-Mistral-24B-Venice-Edition-GGUF/cognitivecomputations_Dolphin-Mistral-24B-Venice-Edition-Q4_K_M.gguf
```

**Рекомендуется** изменить путь на свой или передавать его через аргументы командной строки (доработка по желанию).

### Запуск

```bash
./MyLlamaApp
```

После запуска приложение загрузит модель (это может занять несколько секунд). Затем появится приглашение `Ввод:`. Введите ваш вопрос, нажмите Enter — модель сгенерирует ответ.

Для завершения диалога введите `выход` или `.`.

### История

Все диалоги (запрос + ответ) сохраняются в файл `C:/LLM_CPP/history.jsonl` (путь также можно изменить). Каждая запись — JSON-объект с полями `"Запрос"` и `"Ответ"`.

## Примечания

- Код использует системный промпт: *"Ты — Таисия, дружелюбный помощник. Отвечай на вопросы пользователя по существу, не выдумывай лишнего."* — вы можете изменить его в `main.cpp`.
- На Windows установлена кодировка UTF-8 для корректного ввода/вывода кириллицы.
- Если вы получаете ошибку `llama_tokenize` или подобную, убедитесь, что версия `llama.cpp` совместима с API, используемым в коде (функции `llama_model_get_vocab`, `llama_tokenize` и т.д. присутствуют в актуальной версии).
- Для ускорения на GPU установите `mparams.n_gpu_layers = 999` (в коде уже стоит). При отсутствии CUDA сборка должна использовать CPU.

## Возможные проблемы и их решение

| Проблема | Решение |
|----------|---------|
| Ошибка `llama.h not found` | Убедитесь, что подмодуль `llama.cpp` скачан и в нём есть `llama.h`. |
| CUDA не найден | Установите CUDA Toolkit или отключите `GGML_CUDA`. |
| Модель не загружается | Проверьте путь к файлу `.gguf` и его целостность. |
| Некорректный вывод кириллицы | В Windows должна быть включена кодировка UTF-8 (код уже вызывает `SetConsoleOutputCP(CP_UTF8)`). |
